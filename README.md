<h2>🛠️ Installation Steps:</h2>

<p>1. Clone the repo</p>

```
git clone git@github.com:Joachim-masson/WCS-NodeQuest.git
```

<p>2. Create the .env file by duplicating the .env.sample file</p>

<p>3. Enter NAME=userName and CAMPUS=typeOfSchool</p>

<p>4. Open a terminal</p>

<p>5. run node.js</p>

```
node.index.js
```
